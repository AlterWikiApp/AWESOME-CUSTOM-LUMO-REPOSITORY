## 📥 How to Contribute

### Option A: Pull Request (Recommended)
1. Fork this repository.
2. Create a new branch (`git checkout -b feature/my-lumo-name`).
3. Create a `.md` file in the appropriate folder (`lumos/<category>/`).
4. Commit and push.
5. Create a Pull Request here.

### Option B: Open an Issue
If you need help or have questions, open an Issue first.

## ✅ Acceptance Criteria

Your contribution will be accepted if:
- [ ] Correct folder chosen (`lumos/<category>/`)
- [ ] All required fields filled
- [ ] No harmful code included
- [ ] No hate speech
- [ ] No deception (real people must have disclaimers)

---

## 🚫 Rejection Reasons

Your contribution will be rejected if:
- [ ] Contains hate speech against protected groups
- [ ] Incites illegal activities or violence
- [ ] Attempts to steal data (emails, passwords, etc.)
- [ ] Is a duplicate of an existing Lumo
- [ ] Is spam or nonsense
- [ ] Promotes totalitarian or extremist ideologies (any direction)

## 🆘 FAQ

**Q: Can I submit without a GitHub account?**  
A: No, please sign up. This helps with accountability.

**Q: What happens if my Lumo is rejected?**  
A: You will receive feedback and can resubmit after fixing issues.

**Q: Can I share my Lumos elsewhere?**  
A: Yes, but please link back here.

**Q: Who is liable for issues?**  
A: Each user takes responsibility. We review in good faith.

**Q: Do I lose copyright on my submissions?**  
A: No, you keep ownership. You grant a free license for others to use it.
