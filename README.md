## 🔍 What is this?

Here you will find shared configurations for Custom Lumos:
- **System Prompts** (Role, Behavior, Instructions)
- **Conversation Starters** (Optional, displayed at the start of chats)
- **Usage Tips** (When this Lumo is most useful)

Anyone can copy these configurations and create them in their own account.

## 🚀 How to Use a Custom Lumo

### Quick Steps

1. **Find** a Lumo you like (browse folders under `lumos/`).
2. **Copy** the content of the **Instructions (System Prompt)** field.
3. **Optional:** Copy any **Conversation Starters** listed below the instructions.
4. Open Lumo → **Tools** → **Custom Lumos** → **+ Create**.
5. Paste the prompt and (optionally) add the conversation starters.
6. Save and start chatting!

---

### Important Notes

| Feature | Where to find it | When to use it |
|---------|-----------------|----------------|
| **Instructions** | Main part of the file | **Always** (required) |
| **Conversation Starters** | Below instructions | Recommended for Roleplay, Creative, Funny |
| **Usage Tips** | Bottom of file | Read for best results |
| **Disclaimers** | Safety section | Check if impersonating a person |

📝 **Free Account Needed:** You'll need to register a free account with proton
⚠️ **Free Mode Users:** You can only have one Custom Lumo active at a time. Deactivate the current one before adding a new one.
💡 **Pro Tip:** For Roleplay Lumos, always use the Conversation Starters to get into character faster!

## 🤝 Contribute

Have a Custom Lumo to share?
Read the [Contributing Guidelines](./CONTRIBUTING.md) before submitting.

### Quick Summary

| Step | Action |
|------|--------|
| 1 | Fork this repository |
| 2 | Create a new Lumo file in the correct folder (`lumos/<category>/`) |
| 3 | Submit a Pull Request (PR) |
| 4 | Wait for moderator review (daily cycle) |
| 5 | Once approved, it gets merged! |

**Requirements:**
- You need a GitHub account to contribute
- Use the template in `templates/LUMA_TEMPLATE.md`
- Follow all safety rules (see Section 5)
- Please be nice

🚀 **First time contributor?** Open an Issue first if you need help!
